## Tech Stack Used
- **Plotly**: A powerful library for creating interactive plots and visualizations.
- **Python**: The core programming language used to implement the application.
- **Streamlit**: A framework for building interactive, web-based applications.
- **Yahoo Finance API**: Used to fetch real-time financial data for stocks.
- **Financial Modeling Prep API**: Utilized to retrieve detailed company financials, stock prices, and income statements.
- **LangChain**: Framework for building conversational AI applications.
- **LangGraph**: Tool for creating and managing graph-based workflows.

## Features
- Fetches real-time stock data using Yahoo Finance API and Financial Modeling Prep API.
- Supports multiple time periods (1d, 1wk, 1mo, 1y, max).
- Visualizes candlestick and line charts using Plotly.
- Displays stock metrics, including last price, daily change, high, low, and volume.
- Provides technical indicators such as Simple Moving Average (SMA 20) and Exponential Moving Average (EMA 20).
- Sidebar functionality for selecting stock tickers, chart types, and indicators.
- Real-time stock prices displayed in a sidebar for selected stocks.
- Generates markdown reports for company financials, income statements, and stock price information.
- Implements a workflow system using LangGraph for structured decision-making based on user queries.
